# SafuNet

SafuNet is a self-custody crypto wallet for BNB Smart Chain, in the browser and as an installable web app: hold, send and swap tokens, and let Guardian flag risky tokens before you buy them.

- Website and app: https://safunet.com
- Community and support: https://t.me/reflectocoin

This repository holds public information about the project only. It contains no application source code.
